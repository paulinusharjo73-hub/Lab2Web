2. Struktur tabel menggunakan `thead`, `tbody`, `tfoot`, `caption`, dan `colspan`.
3. Form registrasi mahasiswa.
4. Radio button dan checkbox.
5. Select dan textarea.

8. Multimedia menggunakan `audio` dan `video`.

## Jawaban Pertanyaan Praktikum

### 1. Apa fungsi `<table>`, `<tr>`, `<th>`, dan `<td>`?

`<table>` digunakan untuk membuat struktur tabel. `<tr>` digunakan untuk membuat baris. `<th>` digunakan untuk membuat sel header. `<td>` digunakan untuk membuat sel data.

### 2. Apa perbedaan `<th>` dan `<td>`?

`<th>` digunakan sebagai kepala/header tabel, sedangkan `<td>` digunakan untuk data pada tabel.

### 3. Apa fungsi colspan pada tabel?

`colspan` digunakan untuk menggabungkan beberapa kolom menjadi satu sel.

### 4. Apa fungsi `<form>` dalam HTML?

`<form>` digunakan untuk membuat bagian halaman yang menerima input dari pengguna.

### 5. Apa perbedaan radio button dan checkbox?

Radio button digunakan untuk memilih satu pilihan dari beberapa pilihan yang memiliki nama yang sama. Checkbox dapat digunakan untuk memilih satu atau beberapa pilihan.

### 6. Mengapa `<label>` sebaiknya terhubung dengan id input melalui atribut `for`?

Agar label terhubung dengan input yang sesuai sehingga struktur form lebih jelas dan pengguna dapat berinteraksi dengan input melalui label.

### 7. Apa perbedaan `<textarea>` dengan input type text?

`input type="text"` digunakan untuk input teks yang relatif singkat, sedangkan `<textarea>` digunakan untuk teks yang lebih panjang dan dapat memiliki beberapa baris.

### 8. Apa fungsi semantic HTML seperti `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>`?

Elemen semantic digunakan untuk menyusun struktur halaman berdasarkan maknanya. `<header>` untuk kepala halaman atau bagian, `<nav>` untuk navigasi, `<main>` untuk konten utama, `<section>` untuk kelompok konten, `<article>` untuk konten mandiri, `<aside>` untuk konten pelengkap, dan `<footer>` untuk bagian kaki halaman.

### 9. Apa fungsi required, min, max, dan minlength?

`required` membuat input wajib diisi. `min` menentukan nilai minimum. `max` menentukan nilai maksimum. `minlength` menentukan panjang minimum teks.

### 10. Apa perbedaan elemen `<audio>` dan `<video>`?

`<audio>` digunakan untuk menampilkan atau memutar audio, sedangkan `<video>` digunakan untuk menampilkan atau memutar video.
